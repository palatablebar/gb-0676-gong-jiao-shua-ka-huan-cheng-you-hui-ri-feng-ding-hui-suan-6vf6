# 数据定义

刷卡事件以event_id去重，card保留前导零。route支持1路/01等别名。event_time必须带偏移；业务日为Asia/Shanghai。result仅success可作为行程，失败刷卡隔离。reported为实扣人民币元。票价F1至2026-11-01前为2元，F2为2.50元。

跨线路换乘必须在上一次实际付费行程后60分钟内，恰好60分钟排除。同线路无优惠；零付费行程不能延长换乘锚点。先扣1元换乘优惠，再对卡号业务日施加6元封顶。每条基本票价=实算扣费+换乘优惠+封顶优惠。

运营归属：线路归集到运营方（01→OP_A、02→OP_B、03→OP_C），可用parameters.operators整体覆盖；归属表读取失败或线路未登记归属时行完整保留，operator置空并标记operator_basis=OPERATOR_UNMAPPED。归属依据operator_basis随行流转，归档导出必须携带。

封顶减免分摊：同一卡日内，封顶减免由当日共同形成累计实扣的运营方按各程实扣贡献比例分摊到程（最大余数法，并列按业务键字典序，分币守恒，Σ分摊=Σ减免）；零实扣贡献的运营方不分担。卡日内任一程归属缺失时，该卡日完整保留旧版口径（减免记于发生程，allocation_mode=legacy_fallback）。分摊不改变乘客实扣，卡日实扣合计不超过daily_cap。

清分须与分摊对平：每卡日Σ分摊=Σ减免且总额一致，否则allocation_balanced=false并拦住日结封存（ALLOCATION_UNBALANCED）。封存行必须携带原始刷卡记录_raw、来源行_sources与运营归属依据operator_basis，缺失即拒绝封存（EVIDENCE_MISSING），误删会断掉分摊依据。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
